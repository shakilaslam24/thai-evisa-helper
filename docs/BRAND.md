# DreamFly — ব্র্যান্ড গাইড

সিস্টেমে ব্যবহৃত রঙ ও লোগো।

## রঙ

| রঙ | কোড | কোথায় ব্যবহার |
| --- | --- | --- |
| নেভি | `#101F40` | সাইডবার, হেডিং, প্রাইমারি বাটন |
| সোনালি | `#C19864` | সাজসজ্জা — বার, রেখা, চার্ট, হাইলাইট |
| হালকা সোনালি | `#E5CA9B` | নরম ব্যাকগ্রাউন্ড, গ্রেডিয়েন্ট |
| সাদা | `#FFFFFF` | কার্ড, কাগজ |

### ⚠️ সোনালি রঙে সাদা লেখা দেবেন না

মেপে দেখা গেছে — সোনালি `#C19864`-এ সাদা লেখার কনট্রাস্ট মাত্র **২.৬৪:১**।
পড়া যায় না (মান ৪.৫:১)। তাই:

- **সোনালি** সাজসজ্জার জন্য — বার, রেখা, আইকন, হাইলাইট
- **বাটনে** গাঢ় সোনালি `#8F6A3C` (৪.৮৯:১ — পাশ)
- নেভি `#101F40`-এ সাদা লেখা **১৬.২৫:১** — চমৎকার

ডার্ক মোডে গাঢ় সোনালি দেখা যায় না, তাই সেখানে হালকা `#D6AD78` ব্যবহার হয়।

## লোগো ফাইল

`public/assets/brand/` ফোল্ডারে:

| ফাইল | কোথায় |
| --- | --- |
| `logo-wide-light.png` | সাইডবার, ট্র্যাকিং পেজ (গাঢ় ব্যাকগ্রাউন্ড) |
| `logo-wide-dark.png` | লগইন কার্ড, ইনভয়েস (সাদা ব্যাকগ্রাউন্ড) |
| `logo-mark-light.png` | শুধু প্রতীক — গাঢ় ব্যাকগ্রাউন্ড |
| `logo-mark-dark.png` | শুধু প্রতীক — সাদা ব্যাকগ্রাউন্ড |
| `favicon.png` | ব্রাউজার ট্যাব |

মূল ফাইলগুলোতে চারপাশে অনেক ফাঁকা জায়গা ছিল (১৫০১×৬০১ ছবিতে আসল লোগো
মাত্র ৭২১×২০৬)। ফাঁকা অংশ কেটে ফেলা হয়েছে, নইলে লোগো ছোট দেখাত।

## অন্য কোম্পানির লোগো বসাতে

**Settings → Company details → Logo URL** — সেখানে লিংক দিলে DreamFly লোগোর
বদলে সেটাই সব জায়গায় বসবে। লোগো লোড না হলে কোম্পানির নাম লেখা হিসেবে দেখাবে।
